= DCF Flowers WordPress Theme =

DCF Flowers is a customized WooCommerce theme for Designer Cut Flowers.

== Brand Defaults ==

* Theme name: DCF Flowers
* Logo: assets/images/dcf/logo.svg
* Dark background logo: assets/images/dcf/logo-white.webp
* Favicon: assets/images/dcf/icono.svg
* Primary color: #A7377B
* Secondary color: #D99ABF
* Tertiary color: #F8DCE8
* Quaternary color: #7F2A6D
* Accent color: #EDF5D8
* Typography: Montserrat
* Store focus: cymbidiums, bouquets, floral categories, product cards, videos, seasonal highlights and newsletter capture.

== SEO / AI Search ==

This refresh includes AI-ready structured data, answer-engine friendly metadata, enriched WooCommerce product schema and an llms.txt endpoint.

== Performance ==

Product listings were adjusted to avoid page-output buffering, reduce unnecessary WooCommerce cart-fragment loading, use responsive product images and make live search lighter with nonce protection, debounce and short caching.

== Admin Experience ==

The theme adds a branded login entry at /dcf-admin/ and styles the WordPress login/admin screens with the DCF palette and Montserrat. WordPress still keeps /wp-admin/ internally for core compatibility.
